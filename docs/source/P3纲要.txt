## 1. 总览

### 1.1 P3 定位

P3 不是"让 AI 重新设计排版"，而是：

> 把 P2 的稿件，套用你已有的模板、规范、参数，产出符合目标期刊要求的投稿包。AI 只做检查和修复建议，排版由模板和 CI 完成。

### 1.2 P3 在整体流程中的位置

```text
P4-a 题材初判
  ↓ 排版约束
P1 生信分析
  ↓ 图表（按 P3 规格前置产出）
P2 SCI 写作
  ↓ 稿件包
P3 文稿自动排版
  ↓ 投稿包
P4-b 成稿复审
```

### 1.3 P3 核心原则

- 你的模板和规范是硬约束，AI 只做检查和建议。
- 排版是重点，叙事是骨架，等需求。
- 排版不得升级 claim。
- 排版不得改动数字。
- 排版不得改变证据—主张映射。
- 每条规则必须能构造 FAIL 用例，否则不立。

### 1.4 P3 完整流程

```text
读 P2 稿件包
  ↓
读 P4-a 排版约束
  ↓
读用户已有模板/参数
  ↓
判断目标社（Elsevier / Springer / BMC / Nature / Wiley / Frontiers / MDPI）
  ↓
套用模板 → 排版 → 出图 → 导出
  ↓
自动检查（排版守卫 + 出图守卫 + 降级守卫）
  ↓
生成检查报告
  ↓
生成投稿包
  ↓
交给 P4-b
```

## 3. 排版三铁律

### 3.1 三条铁律

| # | 铁律 | 根因 |
|---|---|---|
| ① | 中文正文**左对齐 + `wordWrap='CJK'`** | 两端对齐时中文没有空格可拉伸，ReportLab 会把余量塞进字与字之间（"字间空隙"的根因） |
| ② | 图件嵌入宽度上限 = **版心宽 160mm**（A4 − 2×2.5cm），**不叠加更小的人为上限** | 曾叠 5.0in 上限，把设计 183mm 的双栏图压到 127mm＝0.69× → 图内标注挤作一团 |
| ③ | 参考文献**一条一段 + 悬挂缩进**，必须**按行切分** | 按 `\n\n` 切分会把整节 8 条并成一整段（"一个引用写完不换行"） |

### 3.2 检测

| # | 判据 | 检测 | 变异用例 |
|---|---|---|---|
| T1 | 中文正文左对齐 | docx `w:jc` | 改两端对齐 |
| T2 | 中文 `wordWrap='CJK'` | docx `w:wordWrap` | 删除 |
| T3 | 图件宽度 ≤160mm | 图片尺寸 | 改 180mm |
| T4 | 不叠加人为上限 | 参数比对 | 注入 5.0in |
| T5 | 参考文献一条一段 | docx 段落结构 | 合并为一段 |
| T6 | 参考文献悬挂缩进 | docx `w:ind` | 改无缩进 |

## 4. 字体纪律三条

### 4.1 三条纪律

| # | 纪律 | 根因 |
|---|---|---|
| ① | 禁止回落 base-14 | 既不嵌入又无 CJK，会**静默丢中文** |
| ② | **逐字字形回退** | 防 `.notdef` **黑框**（PDF 文本层仍可抽字，看字符数抓不到） |
| ③ | 构建前 `assert_glyph_coverage()` 断言字符集全覆盖，构建后 `verify_pdf()` 自检 | 把两个盲区都堵上 |

## 5. 结构序判定

### 5.1 四种合法结构

**S1 默认序（BMC 系）**：

```
题录页 → 结构式摘要 → 关键词 →
引言 → 材料与方法 → 结果 → 讨论 → 声明 → 参考文献
```

**S2-a（含独立 Conclusions）**：

```
题录页 → 结构式摘要 → 关键词 →
引言 → 材料与方法 → 结果 → 讨论 → Conclusions → 声明 → 参考文献
```

**S2-b（结果与讨论合并）**：

```
题录页 → 结构式摘要 → 关键词 →
引言 → 材料与方法 → Results and Discussion → 声明 → 参考文献
```

**S2-c（结论节置于讨论之前）**：

```
题录页 → 结构式摘要 → 关键词 →
引言 → 材料与方法 → 结果 → Conclusions → 讨论 → 声明 → 参考文献
```

### 5.2 判定规则

> 导出脚本自检节序，输出实际节序串；只允许 S1 / S2-a / S2-b / S2-c 四种串。

### 5.3 检测

| # | 判据 | 检测 | 变异用例 |
|---|---|---|---|
| T11 | 节序串 ∈ {S1, S2-a, S2-b, S2-c} | 标题序列 | 加非法序 |
| T12 | 摘要四段标签齐 + P1 首句 | 段落扫描 | 删结论段 |
| T13 | 关键词 3–8 个、分号分隔 | 切分 | 改 2 个 |
| T14 | 声明 8 项小标题齐 | 小标题扫描 | 删声明项 |

## 8. 双轨行距模板

### 8.1 两轨定义

| 轨 | 行距 | 用途 | 关键差异 |
|---|---|---|---|
| **审稿版** | 双倍行距 | 投稿、审稿 | 内置连续行号 |
| **安全版** | 1.5 倍行距 | 阅读、存档 | 无行号 |

两轨共用一套样式，只改行距和行号开关。

### 8.2 切换

Word 全选 → 改字号/行距，样式会同步生效，**不要逐段手工调**。

需要连续行号时：布局 → 行号 → 连续（审稿版已内置）。

## 12. 图片分流原则

### 12.1 核心规则

> 先分流，再谈参数。90% 的"分辨率不够"是把本该矢量的图存成了位图。

```text
图从哪来？
├─ 软件画的（Origin / GraphPad / Matplotlib / R / AI / Inkscape / PPT）
│     → 导出【矢量 PDF 或 EPS】
│     → 没有 DPI 概念，永不退化
│     → 唯一要求：导出时勾选「嵌入字体」
│
└─ 设备拍的（显微镜 / 电镜 / 相机 / 凝胶成像仪 / CT / 扫描仪）
      → 真位图
      → 按参数卡取 DPI → TIFF + LZW 压缩
```

**一句话**：能用矢量就用矢量，彻底绕开 DPI 之争。

### 12.2 检测

| # | 判据 | 检测 | 变异用例 |
|---|---|---|---|
| F1 | 图表类导出矢量 | 文件类型 | 改位图 |
| F2 | 矢量图字体嵌入 | PDF 字体表 | 去嵌入 |
| F3 | 位图为真位图 | 元数据 | 改插值 |

## 13. 图片参数卡

### 13.1 参数卡

| 图类型 | 格式 | 分辨率 | 单栏像素宽 | 双栏像素宽 | 颜色 |
|---|---|---|---|---|---|
| 图表 / 流程 / 示意 / 架构 | **PDF 或 EPS（矢量）** | 不适用 | — | — | RGB |
| 照片 / 显微 / 电镜 / CT | **TIFF（LZW 压缩）** | **600 dpi** | 2008 px | 4110 px | RGB |
| 凝胶 / Western blot | **TIFF（LZW）灰度** | **600 dpi** | 2008 px | 4110 px | Grayscale 8-bit |
| 照片+标注（组合图） | **TIFF（LZW）** | **600 dpi** | 2008 px | 4110 px | RGB |
| 线条图（只能存位图时） | **TIFF（LZW）** | **1200 dpi** | 4016 px | 8220 px | 位图/灰度 |

### 13.2 为什么是这些数

- 600 dpi 同时满足 Wiley 区间上限（600）与 MDPI 建议值（600），且是 Elsevier/Springer 底线（300）的两倍。
- 1200 dpi 按 Springer 线条图最高要求取，覆盖 Elsevier 的 1000。

### 13.3 其余设置

| 项目 | 值 |
|---|---|
| 图中字体 | **Arial 或 Helvetica**，全图统一 |
| 正文字号 | **8 pt**（底线 7 pt） |
| 上下标 | ≥ 6 pt |
| 子图标签 A/B/C | 10–12 pt **加粗** |
| 线宽 | **0.5–1.5 pt**（底线 0.25 pt） |
| 图题位置 | 图**下** |
| 表题位置 | 表**上** |
| 图注 | 独立成段，不贴在图上 |
| 文件命名 | `Fig1.tif` / `Figure_1.pdf`，按正文出现顺序 |
| 单文件 | **< 10 MB**（Wiley 硬规定） |

## 14. 像素宽计算

### 14.1 公式

```
像素宽 = 宽度(cm) ÷ 2.54 × DPI
```

### 14.2 常用结果

| 宽度 | 300 dpi | 400 dpi | 600 dpi | 1200 dpi |
|---|---|---|---|---|
| 单栏 8.5 cm | 1004 | 1339 | **2008** | 4016 |
| 双栏 17.4 cm | 2055 | 2740 | **4110** | 8220 |

### 14.3 规则

取 8.5 cm 与 17.4 cm 这组不会错。按最小画幅准备，排版时放大比缩小更吃亏，反过来则安全。

### 14.4 检测

| # | 判据 | 检测 | 变异用例 |
|---|---|---|---|
| F23 | 像素宽 = 计算值 ±5% | 元数据 | 改像素 |
| F24 | 非插值放大 | 元数据 | 改 dpi 未改像素 |

## 15. 图片降级顺序

### 15.1 降级顺序

超 10 MB 时按此顺序处理，别直接砍 DPI：

1. **裁掉多余白边**（常能省 20–40%）
2. **确认开了 LZW 压缩**（TIFF 必须开，未压缩体积翻倍）
3. **本就是灰度图却存成 RGB → 转 Grayscale 8-bit**（直接省 2/3）
4. **单栏图别按双栏尺寸导出**（画幅减半 → 体积降到 1/4）
5. **降到 400 dpi**，仍不够再降到 **300 dpi**（四家共同底线，**不能再低**）
6. 仍超限：主图放正文（300 dpi），**原尺寸高清图作 Supplementary Material 单独上传**

### 15.2 检测

| # | 判据 | 检测 | 变异用例 |
|---|---|---|---|
| D1 | 超 10MB 走降级顺序 | 记录扫描 | 直接砍 dpi |
| D2 | 优先裁白边 | 记录扫描 | 跳过 |
| D3 | LZW 压缩已开 | 元数据 | 关压缩 |
| D4 | 灰度图未存 RGB | 元数据 | 改 RGB |
| D5 | 单栏图未按双栏导出 | 尺寸 | 改双栏 |
| D6 | dpi 不低于 300 | 元数据 | 降 200 |
| D7 | 仍超限走 Supplementary | 记录扫描 | 忽略 |

## 16. 图片禁忌清单

### 16.1 禁忌

| ❌ 做法 | 后果 |
|---|---|
| PS / 看图软件把图"拉大"到 600 dpi | 插值放大，不增加任何真实信息，一查就露馅 |

| 电镜图裁掉关键区域 | MDPI 要求完整呈现；裁剪须同时提交完整原始图 |
| AI 生成/修改数据图 | 学术不端红线 |
| 重复使用图片/泳道 | 学术不端红线 |

## 17. 五格式导出

### 17.1 五格式

用户口径：**pdf + png + tiff + jpg + svg** 五格式齐全。

| 格式 | 用途 | 说明 |
|---|---|---|
| **PDF** | 矢量主图 | 字体嵌入；≤50 MB |
| **SVG** | 矢量备选 | 可编辑；部分期刊接受 |
| **TIFF** | 光栅主图 | LZW；600/1200 dpi |
| **PNG** | 预览 / 投稿审查 | 300 dpi；无损 |
| **JPEG** | Extended Data / 预览 | 300 dpi；quality≥90；≤10 MB |

### 17.2 注意

- JPEG 不得作主图生产文件。
- PNG 仅作草稿/预览。
- SVG 部分期刊不接受，投稿前核对。

## 30. 规则总览

### 30.1 总体规则

1. 用户模板和规范是硬约束，AI 只做检查和建议。
2. 排版是重点，叙事是骨架，等需求。
3. 排版不得升级 claim。
4. 排版不得改动数字。
5. 排版不得改变证据—主张映射。
6. 唯一真源原则。
7. 每条规则必须能构造 FAIL 用例，否则不立。

### 30.2 排版规则

1. 中文正文左对齐 + `wordWrap='CJK'`。
2. 图件嵌入宽度上限 = 版心宽 160mm，不叠加更小的人为上限。
3. 参考文献一条一段 + 悬挂缩进，按行切分。
4. 双轨行距：审稿版双倍 + 行号；安全版 1.5 倍无行号。
5. 结构序 ∈ {S1, S2-a, S2-b, S2-c}。
6. 声明块 8 项齐全。
7. 图表位置：图题在图下、表题在表上。
8. 表格无竖线无底纹。

### 30.3 图片规则

1. 先分流，再谈参数。
2. 能用矢量就用矢量。
3. 位图 TIFF + LZW。
4. 显微图 600 dpi，线条图 1200 dpi。
5. 字体 Arial/Helvetica ≥6 pt。
6. 线宽 ≥0.25 pt。
7. RGB 模式。
8. 单文件 ≤10 MB。
9. 五格式齐全（pdf/png/tiff/jpg/svg）。
10. 图像完整性红线。

### 30.4 字体规则

1. 禁止回落 base-14。
2. 逐字字形回退。
3. 构建前断言字符集全覆盖。
4. 构建后自检字体全嵌入。
5. 中文字符数达标。

### 30.5 导出规则

1. 参考文献先 Convert to Plain Text。
2. 导出 PDF 时嵌入字体。
3. 取消图像压缩。
4. 五格式齐全。
5. 投稿包包含 PDF + 源文件 + BibTeX + 图表源文件。

### 30.6 消融规则

1. 每个 A 档判据至少 1 个变异用例。
2. 变异用例必须能抓到。
3. 先 FAIL 后 PASS 是唯一有效证据。
4. 抓不到 = 空规，不得计入"通过"。
5. 休眠比例 ≤ 20%。
6. GLOBAL 占比 ≤ 10%。
7. 锚点必须唯一。
