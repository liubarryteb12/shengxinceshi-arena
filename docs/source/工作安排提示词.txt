# P1–P4 端到端验证 · 总指令（AI Agent 执行版）

> 版本：1.0
> 用途：一并发给 Agent，Agent 按此驱动云端 GitHub Actions 执行端到端验证
> 原则：完全按对应论文的分析思路走，不做自定义；只验证体系能否正常工作

---

## 0. 总任务定义

```yaml
task:
  name: P1-P4 端到端验证
  goal: 验证 P1-P4 体系在真实 GEO 数据上能否端到端跑通
  constraints:
    - 数据集样本量 < 12（基础集）
    - 完全按对应论文的分析思路执行
    - 不做自定义分析
    - 所有数据由云端 GitHub Actions 自动下载
    - 所有判据必须能过消融实验
  environment:
    execution: GitHub Actions（公开仓库，无时间限制）
    workspace: 云端 Linux
    local_agent: 用户本地（负责驱动）
    data_source: NCBI GEO FTP
  outputs:
    - 每阶段产出对应接口文件
    - 每阶段跑通变异测试
    - 最终产出测试报告
  success_criteria:
    - P4-a → P1 → P2 → P3 → P4-b 全链路跑通
    - 所有接口文件字段完整
    - 所有 A 档判据先 FAIL 后 PASS
    - 休眠比例 ≤ 20%
    - GLOBAL 占比 ≤ 10%
```

## 1. 执行总流程

```text
[阶段 0] 环境初始化
    ↓
[阶段 1] P4-a 题材初判
    ↓
[阶段 2] P1 生信分析（云端 GitHub Actions）
    ↓
[阶段 3] P2 SCI 写作
    ↓
[阶段 4] P3 文稿自动排版
    ↓
[阶段 5] P4-b 成稿复审
    ↓
[阶段 6] 端到端闭环验证
    ↓
[阶段 7] 测试报告
```

**执行顺序规则**：

1. 严格按阶段 0 → 7 顺序执行。
2. 每个阶段完成后，检查验证点，全通过才进入下一阶段。
3. 任何阶段失败，记录错误，不跳过，不掩盖。
4. 基础集先跑通，再跑进阶集。

## 5. GitHub Actions Workflow 模板

```yaml
# .github/workflows/end_to_end_validation.yml
name: P1-P4 End-to-End Validation

on:
  workflow_dispatch:
    inputs:
      dataset_id:
        description: 'GEO dataset ID (e.g., GSE7451)'
        required: true
      dataset_stage:
        description: 'basic / advanced'
        required: true
      paper_pipeline:
        description: 'Analysis pipeline from paper (JSON)'
        required: false

jobs:
  validate:
    runs-on: ubuntu-latest
    timeout-minutes: 360

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup R
        uses: r-lib/actions/setup-r@v2
        with:
          r-version: '4.3.1'

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install system deps
        run: |
          sudo apt-get update
          sudo apt-get install -y libcurl4-openssl-dev libssl-dev libxml2-dev

      - name: Install R packages
        run: |
          Rscript -e 'install.packages(c("BiocManager", "jsonlite", "yaml"))'
          Rscript -e 'BiocManager::install(c("GEOquery", "limma", "affy", "DESeq2", "clusterProfiler"))'

      - name: Install Python deps
        run: |
          pip install -r requirements.txt
          pip install GEOparse pandas numpy matplotlib seaborn

      - name: Download dataset
        run: |
          python scripts/download_geo.py \
            --dataset ${{ inputs.dataset_id }} \
            --output inputs/raw/

      - name: Run P1 analysis
        run: |
          python scripts/run_p1.py \
            --workspace . \
            --dataset ${{ inputs.dataset_id }} \
            --pipeline '${{ inputs.paper_pipeline }}'

      - name: Run mutation test
        run: |
          python scripts/guard_selftest.py

      - name: Upload results
        uses: actions/upload-artifact@v4
        with:
          name: results-${{ inputs.dataset_id }}
          path: |
            analysis/outputs/
            analysis/_index/
            analysis/_runs/
            02_writing/
            03_typesetting/
            04_journal/
```
